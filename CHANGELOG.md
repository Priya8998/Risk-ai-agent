# Project Development Changelog

This file records the development progress of the simplified RISK AI agent dissertation project.

## Completed Development

### Game Environment
- Created a simplified six-territory RISK map.
- Implemented two-player gameplay.
- Implemented reinforcement logic.
- Implemented dice-based combat.
- Implemented territory capture.
- Implemented winner detection.
- Added a maximum turn limit to prevent endless games.

### AI Agents
- Implemented Random Agent as the baseline.
- Implemented Rule-Based Agent.
- Implemented Heuristic Agent.
- Implemented Monte Carlo Agent using repeated battle simulations.

### Evaluation
- Added win/loss/draw tracking.
- Added attack and capture metrics.
- Added army-loss metrics.
- Added agent decision-time measurement.
- Added Monte Carlo simulation-count tracking.
- Added reproducible random seeds.
- Added alternating starting positions for fairness.

### Testing
- Added automated unit tests for the game engine.
- Added reproducibility validation.

### Final Experiments
- Completed 3,000-game reproducible evaluation.
- Compared all six agent pairings.
- Generated final agent summary.
- Generated head-to-head results.
- Analysed Player 1 and Player 2 starting-position effects.
- Generated final graphs and statistical summaries.

### Documentation
- Added README.
- Added system architecture documentation.
- Added methodology documentation.
- Added results documentation.
- Added dissertation poster.
